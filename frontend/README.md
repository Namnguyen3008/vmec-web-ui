# VMEC Healthcare — Frontend Web Application (Next.js 16)

Giao dien nguoi dung hien dai xay dung tren Next.js 16 (App Router, Turbopack, Tailwind CSS), tich hop he thong trich dan thuan co so du lieu (Pure Database-Driven Citations) va ho tro chuyen doi 3 vai tro: Benh nhan, Bac si, Le tan.

## 1. Yeu Cau Moi Truong
- Node.js >= 20.x
- npm hoac pnpm

## 2. Cai Dat & Khoi Chay
```bash
npm install
npm run dev
```
Truy cap trinh duyet tai: http://localhost:3000

## 3. Bien Dich Production
```bash
npm run build
```
